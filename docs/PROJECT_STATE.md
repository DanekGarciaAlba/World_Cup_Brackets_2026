## Summary

World Cup Brackets 2026 is a Next.js / TypeScript web app for a free, points-only FIFA World Cup 2026 prediction pool. It should feel competitive and premium, but it must never include money, betting, odds, wagers, deposits, payouts, bookmakers, or gambling mechanics.
